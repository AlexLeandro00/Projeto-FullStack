# Gestor Doméstico

Projeto de estudo que tem como objetivo criar um assistente inteligente 
para gerenciar recursos domésticos (água, areia de gato, etc.), 
avisando quando está próximo o momento de repor cada item.

## Status
🚧 Em desenvolvimento — projeto de aprendizado.

## Tecnologias planejadas
- Python
- Banco de dados (SQLite)
- API da Anthropic (Claude) com function calling
